# 动作教学展示规范

V0.3.0 先使用正文中的原创文字和进阶表，不加入未经人体姿势检查的图片。`src/content/docs/` 仍是唯一教学正文来源；本文件只规定格式，不维护另一份动作文案或网页内容。

三篇动作文章均包含七列表格，顺序固定：**动作名称、难度、目标肌群、起始姿势、动作过程、常见错误、下一难度**。表格提供速查，正文解释场地、呼吸、负荷、退出方式和安全限制。难度为能力描述，不是按周数自动升级的等级；下一难度表示可选方向，须满足正文条件。

- 俯卧撑：靠墙 → 可靠高位 → 地面标准 → 可控节奏或停顿。
- 拉力：较直立低杠 → 调整角度；另一路学习脚辅助垂直拉 → 具备全体重控制后尝试标准。
- 双杠：脚辅助支撑 → 脚辅助屈伸 → 具备肩部范围与承重控制后尝试标准。

将来做结构化组件时，应从同一正文的结构化内容派生展示，并保留无图可阅读版本。若新增矢量图，需逐帧检查支撑点、关节方向、重心、运动路径和退阶条件，再发布；不能确认准确时继续使用文字。不得使用未授权照片、视频截图或虚构作者经历。
