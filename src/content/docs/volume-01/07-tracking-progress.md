上次做了十次俯卧撑，这次十二次，算不算进步？如果这次动作更浅、速度更快，答案未必清楚。**判断进步先固定比较条件，再结合动作能力、执行和恢复；外形与体重只是其中一部分。** 记录越简单、越能持续，往往越有帮助。

## 先给“做了一次”一个一致意思

选好适合自己的动作版本，按第三册教学确定起始位置、舒适活动范围和控制要求。以后比较时，尽量用同样标准。这里不要求所有人都达到竞技标准，而是不要今天一种算法、下周另一种。

俯卧撑要记清是靠墙、跪姿还是其他正式教学版本，并尽量保持支撑位置、范围和节奏一致。身体明显塌下、活动范围缩短或已经无法控制时，不要继续把变形次数加进规范次数。换了更难版本，可以另起一行，次数少了也不一定退步。

例如“靠墙，两组各八次，最后几次仍稳定”和“靠墙，两组各十次，但后半段明显变浅”提供的信息不同。日志不需要给自己打高分，诚实描述更有利于决定下次是否维持难度。

## 引体向上，记录辅助与范围

不要只写“做了五次拉”。脚踩地的低杠拉、借助不同程度辅助的动作、标准引体，比较条件差别很大。记清版本、辅助方式、完成范围以及是否借力，才知道变化来自哪里。

同样次数下，动作更稳、所需脚部帮助更少，可能也是能力改善。换杠高、脚的位置或辅助方式后，先把它作为新条件记录，别把两组数字直接相减。本书不要求新手为了测进步去尝试尚不具备能力的高杠悬挂。

没有安全设施时，记录“拉力暂缺”比编造一次完成更好。找到条件后再建立基线，不能用危险桌边测试来补一个数字。具体动作分级请看[引体向上篇](../volume-03/03-pull-ups.md)。

## 控制和稳定性也值得写

动作是否更顺畅、能否保持呼吸、左右是否更接近、是否需要更多借力，都是有用线索。你可以写“这次能慢慢下放”“膝盖方向比上次稳定”，不必为这些描述发明复杂评分。

同样，也不要把感觉当诊断。一次左右不一样，不一定有结构问题；持续明显不对称、疼痛或日常功能受影响时，应寻求专业评估，而不是根据日志自行做康复处方。

## 先记录出席，再记录更多

周计划本来两次，实际稳定完成两次，就是一个重要过程结果。写下没完成的原因：加班、场地关闭、生病还是量太大。有了原因，下一周才能改时间、备选场地或训练量；空白不应自动翻译成懒惰。

恢复也要留一格。看看下一次练习前是否大致恢复、睡眠怎样、日常活动有没有明显受影响。连续几次表现下降且疲劳增加时，先检查饮食、睡眠、疾病与训练安排，不把下降当作必须更拼的信号。

## 可以直接复制的 Markdown 日志

把下面内容复制到本地笔记或纯文本文件，重复添加行即可。“无”和“未记录”都可以写，不需要补成看起来漂亮的数据。表内是空模板，没有虚构训练成绩。

```markdown
## 本周训练记录
目标：
计划时段：
备选时段或场地：

| 日期 | 动作版本与辅助条件 | 各组规范次数或时长 | 控制与余力感受 | 不适及恢复 |
| --- | --- | --- | --- | --- |
|  |  |  |  |  |
|  |  |  |  |  |

本周计划次数：
本周完成次数：
睡眠与精神简记：
下次保留的一件事：
下次调整的一件事：
```

时长用于相应动作，不必把所有动作都换成计时挑战。次数和余力都是在安全范围内观察，不要求每周测最大值；动作需要的休息也应大致一致。记录可以在一组后简写，训练结束再补一句，别让写笔记占据大部分练习。

## 体重趋势怎样放进来

体重记录是自愿的。愿意称、也不会因此焦虑时，可每周选几天，在起床如厕后、进食前、相近衣着和同一台秤下记录，看周平均或长期方向。无需早晚反复检查，也别把饭后数字和晨起数字硬比较。

增肌、减脂和维持的目标不同，体重方向要结合目标解释。单次体脂秤的“肌肉量”还会受到水分影响，不能把一天变化当真实组织增减。没有称重，也可以通过稳定训练、衣服松紧和身体状态复盘。

## 腰围和其他围度，先固定位置

如果想量腰围，选同一个明确位置和相近时间，站立自然、腹部放松，在正常呼气后读数；软尺保持水平，不勒紧，也不刻意吸肚子。本书建议自我观察可固定在肋骨下缘与髂骨上缘之间的中点，并把位置写下来；不把此处读数直接套其他测量位置的健康阈值。

上臂、大腿等围度同样应固定位置、姿势和是否刚训练。偶尔重复测量可以检查误差，不需要每天量。围度会受到测量方法、水分和脂肪影响，不能仅凭增加一厘米就宣布长了相应肌肉。

## 拍照完全自愿，先保护隐私

不想拍就不拍，它不是成功必需品。愿意记录时，可穿普通贴身运动衣，在相近光线、距离和自然站姿下，隔一段时间拍正面、侧面或背面，不必收腹摆姿势，也不需要公开身体。

优先保存在自己控制的本地位置，检查相册云同步和共享设置；避免人脸、住址、证件、镜中他人和定位信息进入画面。不要把私人身体照提交到本项目 GitHub、公开群或不明健身应用。想请人看动作时，也先确认对方身份、用途和传播范围。

## 两周、四周怎样复盘

两周先看执行和恢复：哪些时段能用，动作是否适合，是否有不适。四周再把可比表现和目标放到一起，决定维持、降低还是小幅提高难度。这些是本书便于执行的检查节点，不是保证两周或四周有外形变化。

```markdown
## 阶段复盘
观察区间：
计划与实际完成情况：
同条件下改善的动作或控制：
恢复与不适：
体重/腰围趋势（自愿，可留空）：
照片比较（自愿，可留空）：
可能影响判断的变化：
下一阶段只调整的一件事：
```

比如次数没有增加，但动作更稳、缺席减少、疲劳也更可控，可以先维持。若只是最近两次熬夜后下降，先恢复作息；若长期没有改善，再检查刺激是否合适。不因一次好成绩立即升级，也不因一次差成绩推翻整个计划。

## 用记录帮助生活，不用它管住生活

本章适用于一般健康成年人。记录不能诊断疾病或决定康复；疼痛、胸痛、异常气短和晕厥感等问题应停止相关活动并按情况就医。若称重、围度或拍照让焦虑不断增加，就减少或停止这些项目，必要时寻求帮助。

今天只需复制第一张表，选一个安全熟悉的动作建立描述，训练后写一句恢复感受。外形不是训练成功的唯一标准，能更稳定地使用身体、保持活动和照顾自己，都值得被看见。
