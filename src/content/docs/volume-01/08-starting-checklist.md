读完前面几章，你可能已经愿意开始，却仍有一点犹豫：今天到底先做什么，买鞋、拍照，还是去公园试一次引体？**开始前最重要的是确定一个适合自己的安全起点，给它留出时间，然后进入已有的基础教学。** 不需要先把所有准备做到完美。

这一章是第一册的出口，帮助你决定接下来读哪里、检查什么。它不另写一套第 0 周计划，也不要求今天测试最大次数。详细按天执行的内容已经在[第四册第 0 周](../volume-04/01-week-zero.md)，这里把开始前的关键决定串起来。

## 把目标写成今天能影响的事

“想有好身材”可以保留，但再加一句自己能做的事：例如“先建立每周两次适合自己的训练，学会基础动作并做简单记录”。不要把未经评估的体重、体脂或高阶动作当第一周必须完成的指标。

也可以说明为什么想练：希望爬楼更轻松、肩背更有力量、从久坐中恢复一点活动。目标越贴近自己的生活，越容易判断时间和场地是否值得投入。无需向别人证明理由足够宏大。

如果你发现目标主要来自对自己身体的厌恶，先把焦点放回能力与生活。训练可以成为照顾身体的方式，不应变成用疼痛、饥饿和不停比较惩罚自己的规则。

## 根据身体条件选择起点

先承认当前水平，不急着做标准动作。能安全完成靠墙俯卧撑，也可以从那里开始；深蹲只做到舒服且能控制的范围，也属于练习。当前做不了引体向上和双杠臂屈伸，并不影响先建立其他基础。

体重较大、长期没活动或体能较低时，自身重量可能已经很有挑战。先选更容易的版本、较少训练量和可退出的场地。具体动作选择请阅读[第三册第一章](../volume-03/01-first-workout.md)，不要仅凭本章的动作名称开始模仿。

有伤病、慢性疾病、近期手术、孕期或医生限制活动等情况，应先结合专业建议确定适合自己的方式。这不等于所有成年人开始轻量活动前都必须做同一种检查，而是本书普通成人示例不能覆盖个体医疗问题。

## 知道什么情况应该停

活动中出现胸痛、明显异常气短或晕厥感，应停止并根据严重程度及时就医，严重或持续症状需要尽快处理。关节尖锐疼痛、动作中突然明显不适，也不应为了完成次数继续。

正常用力、短暂疲劳与危险症状不能简单混为一谈。初学者不必学会全部诊断，但要允许自己停下来。不要用“坚持才有效”压过身体给出的警报，也不要依靠网上一句话决定某种持续疼痛一定安全。

## 先选一个主场地，再留备选

家中可以检查防滑地面、结实墙面、伸展空间与周围人员；公园则要看可靠设施、地面、开放时间与天气。选主场地时把来回路程也算进去，别只看照片觉得很漂亮。

备选不用和主场地完全相同。雨天不能用杠时，可以暂时回家做已经会的基础部分，并把拉力缺项记下来；不能为了保持动作清单完整，冒险找桌边或门框悬挂。场地组织可以参考[不去健身房怎样开始](04-training-without-gym.md)。

穿方便活动、不会明显妨碍动作的衣物，准备饮水即可。没有必要先买一整套装备。确有地面舒适或安全需要，再根据实际情况补充用品；产品的“专业”字样不是开始前通行证。

## 单杠、双杠要看什么

先看固定处、明显松动、破损锈蚀、锋利边缘和表面湿滑，确认周围没有容易碰撞的物体。杠的高度与间距还应适合自己的能力，能安全上下和退出，不靠危险跳跃进入。

有任何疑点就不使用，目视检查也不能保证承重。不要通过猛晃、多人同时挂上去等方式自行验收设施。选择脚能踩地、难度能调整的低杠时，同样要检查地面防滑与固定条件；不能因杠低就默认没有风险。

双杠存在，不意味着新手必须立即做臂屈伸。先了解正式教学的起点、范围与限制，再判断是否适合。身体不适合或设备不可靠时，今天暂不使用，是正常决定。

## 选基础动作，不拼收藏数量

起步要知道推、拉、下肢与核心各有位置，不把喜欢的动作当全部训练。第三册已有[俯卧撑](../volume-03/02-push-ups.md)、[引体向上](../volume-03/03-pull-ups.md)、[双杠臂屈伸](../volume-03/04-dips.md)、[下肢](../volume-03/05-legs.md)和[核心](../volume-03/06-core.md)教学，可以按当前条件阅读。

第一周优先使用已理解、能降低难度、能安全结束的版本，不追求每一篇都实践一遍。没有安全拉力条件就先记录，随后寻找场地，不能将缺少条件解释成背部永远不需要练。

组次和休息直接沿用相应入门教学，不在这份清单里叠加新的挑战。第一次结束后还愿意下次继续，比把所有收藏都做完更适合作为开始的判断。

## 给每周两次左右的起步留位置

在日历里先放两个现实可用、相隔至少一天的时段，再写一个备选。对一般健康新手，这是本书便于起步的实践安排；WHO 对成人主要肌群强化活动有每周至少两天的公共健康方向，但完整健康建议还包括有氧活动和减少久坐，并非两次训练就涵盖全部。

具体一周组合接着看[第三册周训练安排](../volume-03/07-weekly-schedule.md)。若时间紧，可以降低单次安排并保留热身与休息，不把碎片时间变成随时测试极限。生病或恢复不好时需要调整，不能为了打勾硬练。

例如工作日晚上在家、周末去可靠公园，是一种场地分配；实际周几由你决定。这里只需要确定能用的时段，不必今天就把未来十二周逐天排满。

## 吃饭和记录，先做到基础

三餐保留主食、蛋白质食物与蔬菜水果，不因开始训练就突然节食或大量加餐。先读[普通人的一日三餐](../volume-02/01-daily-meals.md)，再按问题选择[蛋白质篇](../volume-02/03-protein.md)或[外食篇](../volume-02/07-eating-out.md)。补剂不是开始条件。

记录只需日期、动作版本、完成情况和感受，复制[上一章的 Markdown 表格](07-tracking-progress.md)即可。体重、围度和照片都自愿，身体照片不上传本项目或公开仓库。日志帮助你调整，不是监督自己每天必须进步。

## 第一周行动入口

先完成下面十项检查，再进入第三册第一次练习；需要逐天安排，就按第四册第 0 周继续，之后衔接[第 1–2 周](../volume-04/02-weeks-one-two.md)。本章不重复其中的热身、组次和按天任务，避免出现两套互相竞争的计划。

第一周结束时问三件事：安排是否现实，动作是否适合，恢复是否允许下一次继续。缺席、下雨或需要降低难度都可以记录并调整，不必把开头的小波折解释成自己不适合健身。

## 新手开始训练前的 10 项检查清单

- [ ] 我写了一个能执行的过程目标，没有固定期限的身材保证。
- [ ] 我了解自己的当前起点，需要个体医疗建议时已先处理。
- [ ] 我知道胸痛、异常气短、晕厥感和尖锐疼痛等情况应该停。
- [ ] 我选好了安全主场地，并知道天气或空间不合适时怎么办。
- [ ] 若使用杠类设施，我已检查明显问题及上下方式，有疑点就不用。
- [ ] 我读过要练的基础动作教学，选了能控制和退出的版本。
- [ ] 我圈出了每周两次左右的起步时段，并留有恢复与备选。
- [ ] 我准备保留正常三餐，不靠极端节食或补剂开始。
- [ ] 我有简单日志，身体测量与照片只按自愿和隐私要求记录。
- [ ] 我知道下一步去第三册学动作、第二册看饮食、第四册做实践。

勾选不是风险认证，不需要假装每项都准备好。有一项暂缺，就明确下一步怎样补；身体或场地存在安全疑点时先解决。今天完成一个具体决定，再进入适合自己的第一次练习，第一册的任务就落到了生活里。
