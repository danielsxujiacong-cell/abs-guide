刚开始训练，购物软件就开始推蛋白粉、肌酸、燃脂胶囊和各种“必备组合”。每一样都说自己不可缺少，很容易让人觉得不先花钱就练不好。**普通食物、合适训练和恢复是基础，补剂可以不买；即使使用，也应知道它解决什么问题、证据到哪里。**

## 蛋白粉就是一种方便来源

乳清、酪蛋白、大豆等蛋白粉，是从相应食物原料中加工得到的蛋白质补充形式，不是自动增加肌肉的药，也不是“喝了就会变成大块头”的激素。消化后仍然给身体提供氨基酸，作用离不开一天总摄入与训练。

普通三餐能满足需要时，不喝完全可以。鱼、蛋、奶、瘦肉和豆制品还带来不同营养，不能只用粉替代大多数正餐。想先检查吃得够不够，可以回到[蛋白质篇](03-protein.md)，而不是按商家默认的每日勺数下单。

它可能有便利性的情况，是长期出差、正餐蛋白质确实不足，或训练后暂时不方便吃饭。先看有没有普通食物能补，再比较价格和耐受。不喜欢喝粉，或者买了容易让自己焦虑，就没有必要强用；方便是选择理由，不是入门资格。

## 一勺粉不等于一勺蛋白质

标签要看蛋白质每一百克或每份有多少、实际一份多重，以及糖和其他成分。不同量勺大小不同，不能把别人的勺数当自己的用量。不要因为包装写“增肌”，就忽略它可能还有大量碳水或其他添加成分。

乳清来自奶，牛奶蛋白过敏者不应使用；乳糖不耐受也应看实际成分和耐受，不能把不含乳糖与不含奶蛋白混为一谈。大豆蛋白也有相应过敏限制。反复腹泻、腹痛或皮疹时不要硬喝，应停止并根据症状寻求医疗帮助。

正常吃饭的人无需为了“吸收更快”在训练结束几分钟内冲粉。若下一顿很快就能吃到，正常进餐即可。粉也不是晚餐赎罪券，不能靠白天挨饿、晚上喝粉补回饮食完整性。

## 肌酸是什么，可能帮助什么

肌酸是人体本来就有、也能从部分食物获得的物质，参与短时间高强度活动中的能量供应。它不是蛋白质，也不是合成代谢类固醇。补充后可能提高部分重复高强度运动表现，配合抗阻训练可能带来额外适应，但每个人的反应不一样。

ISSN 2017 立场文件与 NIH ODS 资料支持它在一些短时间、高强度、间歇活动中的用途，不能直接扩大为“所有运动都有效”或“新手必须用”。轻松散步、技术尚不稳定的第一次俯卧撑，不会因为加肌酸就自动变成有效的渐进训练。

对自重练习者，先看动作、强度和规律性是否已经建立。还没练几次，最有价值的改变通常是学会合适动作、按计划练并睡好，不是补剂叠加。研究中的群体平均效果，不是你能多做几次引体的保证。

## 剂量是研究信息，不是所有人的处方

研究最充分的形式是**一水肌酸**。健康成人研究中常见每日 **3–5 克**维持摄入，也有先短期加载再维持的方案；加载并非必须。本章不建议新手自行使用大剂量加载，也不要求读者开始服用。常规低剂量方案需要持续一段时间才能提高肌肉储量，不是训练前临时喝一次就立即生效。

这里的克数指肌酸产品中对应的肌酸用量，不是任意混合粉一勺的重量，配方不同要看标签。若考虑使用，应先确认身份、健康状况、用药与产品信息是否适用，不把这段研究剂量当个人医疗建议。未成年人、孕期或哺乳期、存在肾脏等相关疾病、正在用药者，不应照搬健康成人建议，应先咨询专业人员。

肌酸可能使体重因肌肉内水分增加而上升，这不等于短期长出了同样重量的肌肉，也不一定是脂肪增加。减脂时如果突然开始使用，秤上趋势可能更难解释，应记录这个变化，而不是立刻削减食物。

## 不适和安全边界要说清楚

部分人会有胃肠不适，单次大量摄入更容易带来问题。按平常需要饮水，不需要强灌水，也不要把肌酸与脱水、极端节食或不明成分的训练前产品混着尝试。出现明显不适就停止，自行不断加量不是排查方法。

现有研究对健康成人常规使用总体较为支持，但不能证明任何人、任何剂量、任何产品、无限期都安全。健康成人试验不能直接替代肾病患者或孕期的安全证据。检查肾功能时还应告知医生自己使用了肌酸，因为相关化验的解释需要结合实际情况，不能自己判断“指标变了也一定没事”。

产品本身也有标签不实、污染和掺入其他成分的风险。优先了解成分、来源与独立质量检测信息，独立检测也不保证一定有效或适合你。不清楚成分的“复合增肌秘密配方”应避开，贵、进口和网红推荐都不能代替证据。

## 所谓燃脂产品，先把钱包收住

“排油”“清宿便”“提高代谢躺着瘦”“专减肚子”等话术，经常把排便、脱水、兴奋感或短期秤重变化包装成脂肪减少。NIH ODS 对减重补充剂的梳理指出，许多产品证据有限，复方和长期安全也有不确定性，不能仅凭前后照片判断。

不要使用来路不明的减重药、泻药、利尿剂或所谓激素类增肌品来改变体形。医疗减重用药属于医生评估与随访范围，不是本书推荐的补剂。保健品也不能因为叫“天然”就自动排除相互作用或不良反应。

咖啡让人清醒，不等于可以无限增加咖啡因或购买强刺激训练前产品。为了喝产品而睡不好，反而破坏恢复。普通入门训练不需要一套粉剂才能开始；把预算留给正常饭菜和生活，完全合理。

## 营销信息怎么判断

| 看到的说法 | 可以追问什么 |
| --- | --- |
| “有研究支持” | 原文在哪里，研究对象与你相似吗？ |
| “提高肌肉量” | 测的是肌肉、水分还是去脂体重，持续多久？ |
| “所有人适用” | 是否排除了疾病、孕期、未成年人和用药者？ |
| “一个月必见效” | 有对照吗，训练和饮食是否同时改变？ |
| “医生或冠军推荐” | 推荐能否替代独立研究，是否存在利益关系？ |

论文也不是看见标题就够了。动物研究不能直接给成人剂量，短期实验不能证明长期外形改变，品牌资助需要披露但不自动决定真假。对照、样本与适用情境都值得看；如果卖家只肯提供聊天截图，不肯给来源，就没有必要替它补齐证据。

“不喝粉就白练”“肌酸能代替训练”“出汗越多脂肪掉得越多”“碳水必须戒掉”，都把复杂事情变成单一口号。先问它是否让你更规律训练、更完整吃饭，还是只制造新的消费门槛。

## 本册最后一个行动建议

先把下一周的普通三餐和训练安排落实。若确实存在一个具体缺口，再考虑最简单、成分明确的解决方式；没有缺口就不必购买。你可以完全不用补剂，把训练和生活过好，不需要向任何购物清单证明自己认真。
