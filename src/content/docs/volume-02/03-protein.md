早餐啃两个包子，午餐一份盖浇饭，晚上吃碗面，你可能一天下来肚子挺撑，但算下来几乎全是碳水和油脂，蛋白质少得可怜。刚在公园练了两组俯卧撑，网上就有人跳出来告诉你：“不喝两大勺蛋白粉，练了全白练！”

别急着打开购物软件去买粉。**先在每天的三餐里，把看得见、吃得着的天然优质蛋白摆上桌，这才是支撑肌肉修复与力量增长的最扎实地基。**

## 为什么自重健身也必须吃够蛋白质？

很多人觉得“我没去健身房大重量卧推深蹲，只是在单杠吊着拉拉引体、在地上做做俯卧撑，不需要那么多蛋白质吧？”

这个想法完全错了。自重健身本质上同样是高强度的抗阻训练。每一次拉起身体、每一次标准推起，胸背肩臂的肌纤维都经历着机械张力的刺激与微细损伤。身体需要足够的蛋白质分解为氨基酸，去修复肌纤维、合成新的肌肉组织，让你下次训练时更有力量。

但蛋白质也不是越多越好。睡得不好、练得不到位，单纯猛啃一斤肉，多余的热量同样会变成脂肪堆在肚皮上。

## 算算你的日常蛋白质目标：1.4–2.0g/kg

欧洲食品安全局（EFSA）对普通成人的基本生存参考摄入量是每天每公斤体重 0.83g，这仅仅是保证不营养不良的底线。

对于**每周有规律进行自重训练、想要肌肉紧致有线条的健康人**，国际运动营养学会（ISSN）推荐的有效范围是：
- **每天每公斤体重 1.4–2.0g 蛋白质**。

拿一个体重 **60kg** 的普通新手来算：
- 每天的总蛋白质摄入目标大约在 **84g – 120g** 之间。

刚起步的新手不需要第一天就死磕 120g 的上限，先稳步吃到 80–90g 左右，就已经能为身体恢复提供极佳的营养支持了。

## 核心常识：100g 肉 ≠ 100g 蛋白质

这是最多新手容易搞混的概念。常有人问：“我今天买了一块 100g 的鸡胸肉吃完，是不是一天 80g 的目标就超标了？”

**绝对不是。食物的总重量，和它里面含有的纯蛋白质重量是两码事。** 肉类里大部分是水分，还有少量脂肪和无机盐。

下面是中国家庭最常用、最容易买到的高性价比蛋白质食物换算表（按煮熟可食部分估算，不用死抠个位）：

| 常见食材（煮熟/日常份量） | 估算摄入份量 | 纯蛋白质含量（约） | 日常购买与备餐心得 |
| :--- | :--- | :--- | :--- |
| **新鲜鸡蛋**（全蛋） | 1 个（中大号） | **6–7g** | 最便宜实惠的来源，白煮、荷包、做汤都行，蛋黄营养丰富不用扔 |
| **纯牛奶 / 鲜牛奶** | 1 盒（250ml） | **7.5–8g** | 早餐标配，看包装配料表只要“生牛乳”即可，普通平价款就很棒 |
| **鸡胸肉 / 去皮鸡腿** | 熟重 100g（约一掌心大） | **22–25g** | 蛋白质王者，去皮鸡腿肉口感更嫩、不发柴，价格同样亲民 |
| **家常瘦猪肉**（里脊/纯瘦肉） | 熟重 100g（约一掌心大） | **20–22g** | 菜市场极好买，切肉丝炒青菜、煮瘦肉汤，完全不需要排斥猪肉 |
| **牛腱子 / 卤牛肉** | 熟重 80–100g（约一掌心大） | **20–25g** | 酱牛肉或卤牛腱，买现成切片或自己炖，高蛋白且极为顶饱 |
| **巴沙鱼 / 鲜虾仁** | 熟重 100g（约掌心大） | **18–20g** | 几乎零脂肪，清蒸鲈鱼、煎巴沙鱼柳或白灼虾，消化负担极轻 |
| **老豆腐 / 北豆腐** | 生重 200g（家常一块） | **14–16g** | 优质植物蛋白代表，炖白菜、煎豆腐，几块钱就能买一大块 |
| **香干 / 豆腐干** | 1 包（约 100g） | **15–18g** | 追剧或加餐神器，蛋白质密度高，注意挑配料油盐不重的款 |

不用每天拿着天平去称，记住“**一掌心肉类约 20g 蛋白，一个蛋约 7g，一盒奶约 8g，一块豆腐约 15g**”，看一眼盘子心里就大概有数了。

## 三餐平均分配，比晚上临时狂补轻松得多

很多上班族的一天是这样度过的：早餐一根油条一碗稀饭（纯碳水和油），中午一碗面条飘两片薄肉（蛋白不到 5g），晚上回到家看着软件发现缺口巨大，赶紧狂啃三块鸡胸肉或者灌两杯蛋白粉，撑得肚子发胀难受。

聪明的吃法是**把蛋白质均匀平摊到早、中、晚三餐**：

- **早餐直接拿下 15g**：不要只喝粥吃包子。煮 1 个鸡蛋，配 1 盒纯牛奶（或者无糖大豆豆浆），再吃你的包子馒头。早晨刚起床，身体就有了充足的原料。
- **午餐稳稳吃够 25–30g**：食堂打菜点一份青椒肉丝或红烧鱼，外加一份家常豆腐，或者外卖点一份黄焖鸡。
- **晚餐轻松补齐 25–30g**：家里炒个肉丝、煎块豆腐、或者煮碗虾仁西红柿面，正常跟家人一起吃，多挑里面的肉蛋豆吃即可。
- **下午如果饿了，加餐 5–10g**：下午三四点工位上饿了，别点奶茶甜点，喝一盒牛奶、嚼一小把毛豆或吃个茶蛋，既解馋又补蛋白。

## 破除关于蛋白质的几个常见误区

1. **“一顿饭只能吸收 30g 蛋白质，多吃全浪费了？”**
   这是早年被歪曲的说法。身体的消化系统非常强大，一顿饭吃下 40g 甚至 50g 蛋白质，胃肠道会放慢排空速度慢慢消化分解吸收，绝不会凭空排掉。正常三餐吃饱吃好，根本不用神经兮兮地卡着 30g 停筷子。
2. **“吃鸡蛋必须把蛋黄扔掉，只吃蛋清？”**
   普通健康成年人每天吃 1–2 个全蛋没有任何问题。蛋黄富含卵磷脂、维生素 A、D、E 和微量元素，丢掉既浪费又失去了大半营养。
3. **“植物蛋白是劣质蛋白，长不了肌肉？”**
   虽然豆制品的部分氨基酸构成和肉类稍有差异，但只要你平时米饭等主食搭配着吃，氨基酸完全可以互补。老豆腐、香干、豆浆都是极其便宜好用的增肌帮手。
4. **“我必须买蛋白粉吗？”**
   蛋白粉只是一种从牛奶或大豆里提取的“便携脱水干粮”。如果你平时肉蛋奶吃得够，**完全没有必要花这笔钱**。它唯一的优势是方便快捷（出差、赶时间没法吃肉时摇一杯），但绝不比一块真正的香煎鸡胸肉或炖牛肉更神奇。

明天早晨起床，就去楼下便利店或早餐摊买个茶叶蛋、拿盒牛奶。把第一顿饭的蛋白质补上，你就已经跑赢了绝大多数盲目节食的人。
